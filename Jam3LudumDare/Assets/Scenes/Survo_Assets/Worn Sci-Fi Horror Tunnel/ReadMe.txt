----------------------------
Setting Up:
----------------------------
Requirements 
Important: Install the following packages as the first step after importing the asset, before loading the demo scene. 
These packages are required for the demo scene and related functionality to work correctly.

Install the following packages using Package Manager:
Input System (version used: 1.14.2)
Cinemachine (version used: 3.1.7)

----------------------------
Render Pipeline Compatibility:
----------------------------
This asset is made for HDRP.
When using the HDRP version, make sure the Demo_Scene_HDRP Global Volume is configured to use the provided volume profile: 
Settings/Worn_Sci_Fi_Horror_Tunnel_Volume 
Assign this profile to the Profile field of the Sky and Fog Volume to ensure the demo scene uses the intended visual settings.

If you are using URP, import the included URP package before using the asset.
Make sure the provided URP Global Volume is selected and used in the demo scene as well.

----------------------------
Prefabs Usage:
----------------------------
Modular Parts (Tunnel_Straight, Tunnel_Curved_45, Tunnel_Curved_90): 
Use Vertex Snap (V key) to precisely snap the parts together. For best results, snap using the top-center vertex of the margin on each part.

Tunnel End Prefab:
The Tunnel_End prefab can be easily positioned using Grid Snapping with a value of 0.1.
